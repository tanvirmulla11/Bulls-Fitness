Bulls Fitness India is a professional gym and training center in Rajkot.  
This website showcases:

- Training Modules  
- Membership Plans  
- Weekly Training Schedule  
- Trainers  
- Fitness Gallery  
- BMI Calculator  
- WhatsApp Contact & Inquiry  

The UI focuses on **premium aesthetics, Desi fitness identity, and smooth animations**.

# ⚙️ Installation & Setup

### 1️⃣ Clone the repository  
```bash
git clone https://github.com/your-username/bulls-fitness-india.git
```
### 2️⃣ Open the project

Simply open:
```
index.html
```

### No backend or additional server setup required.

### 🔧 Customization Guide
### 🌈 Change Theme Colors

### Modify Tailwind utility classes in Index.html such as:
```
text-orange-500
bg-orange-600
from-orange-500
to-red-600
```
### 🖼 Replace Gym Images

Place your images inside the /Images directory.

### 📦 Add New Training Modules

Copy this card template inside the Modules section:
```
<div class="glass-card p-8 rounded-2xl">
  <h3 class="text-2xl font-bold">Module Name</h3>
  <p class="text-gray-400">Description here...</p>
</div>
```
